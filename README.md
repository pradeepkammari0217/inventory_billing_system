# Inventory Billing System

![Logo](logo.png)

A simple Python application to manage products, calculate GST, and generate customer bills.  
This project is designed as a beginner‑friendly billing system with menu‑driven options.

---

## 📌 Features
- Add products with price, category, and GST
- View product list with details
- Generate customer bills with GST calculation
- Save bills into text files for record keeping
- Menu‑driven interface for easy use
